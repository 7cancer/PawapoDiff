# PawapoDiff

日本語原本と英訳版のPowerPointをローカルで比較するWindows用ツールです。図形の配置・サイズ、文字書式、翻訳の表記揺れ候補をブラウザで確認できます。LLM・有料API・外部へのファイル送信は使用しません。

## 利用環境と起動

- Windows 10/11、デスクトップ版Microsoft PowerPoint、Chrome/Edge等。
- **`PawapoDiff-Setup.exe` をダブルクリックするだけで、必要なPython実行環境・依存ライブラリ・画面を自動配置して起動します。** 利用者によるPython・Node.jsの導入や管理者権限は不要です。
- 初回は `%LOCALAPPDATA%\PawapoDiff\versions` に展開し、スタートメニューに「PawapoDiff」を追加します。次回からはそのショートカットで起動できます。セットアップEXEを再実行しても、同じ版は再導入しません。新版は別フォルダーに導入します。
- 必要な環境はEXEに同梱するため、導入・使用時ともインターネット接続は不要です。**PowerPoint本体の導入・ライセンス認証は別途必要です。**
- 不要になった場合はアプリを終了後、上記のPawapoDiffフォルダーとスタートメニューのショートカットを削除してください。自動更新は行いません。
- 終了は起動したコンソールで **Ctrl+C**。ブラウザを閉じるだけではサーバーは終了しません。通常終了時に一時ファイルを削除します。強制終了時はOSの一時フォルダーに `PawapoDiff-*` が残る場合があります。
- **[GitHub Releases](https://github.com/7cancer/PawapoDiff/releases) から公開版の `PawapoDiff-Setup.exe` をダウンロードできます。** リリースページ下部のAssetsにあるEXEを選んでください。`Source code` のZIPにはEXEは含まれません。
- 開発ビルドは [Actions → Windows installer](https://github.com/7cancer/PawapoDiff/actions/workflows/windows-build.yml) の成功した実行のArtifactsからも取得できます。こちらはZIPの展開とGitHubへのログインが必要です。
- ソースのZIPにはビルド済みEXEは含みません。手元で生成する場合は下記のWindowsビルド手順を使います。

## 使い方

1. 「日本語原本」と「英訳版」に、同じページ数・寸法の `.pptx` を選択して比較を開始します。1ファイル15GB（15×1024³バイト）までです。
2. ページ一覧からページを選び、左右・重ね合わせ・画像差分で確認します。枠の色は **青＝書式のみ、オレンジ＝配置・サイズ・回転、紫＝書式と配置の両方、グレー＝画像・追加削除・対応要確認** です。図の番号と変更一覧にカーソルを合わせると対応箇所を両側で強調し、図からは該当リスト項目を表示します。キーボードのフォーカスでも操作できます。**「ハイライト表示（ON／OFF）」** で全表示モードの枠を切り替えられます。
3. 位置とサイズはptで比較します。初期閾値1pt（96dpi相当で約1.33px）を変更して再判定できます。
4. 翻訳チェックで、空の訳文、日本語の残存、同一原文の訳し分けを確認します。候補の下に **日英比較表** を表示します。テキストボックス・表セルの文章を改行（段落・ソフト改行）ごとに分け、原文側が空白を除いて2文字以下の行は表に載せません。原文のない英訳のみの行も表から除外します。短い文章も訳抜け・日本語残存のチェック対象には残します。
5. 同一の日本語原文に異なる英訳がある場合、同じ原文をページをまたいで1行にまとめ、異なる英訳を並べて各訳の出現ページを表示します。該当行を淡い黄色にし、**「表記揺らぎの可能性あり」** と注釈を付けます。行内の空白は正規化し、空の訳文は訳抜けとして区別します。日英の改行数が一致しない場合は、各原文行に英訳ボックス全体を表示して「行の対応は要確認」と注記します。意味による行の対応付けは行いません。
6. HTMLレポートには全ページの比較画像、色分け、変更一覧、翻訳チェック、集約した日英比較表を埋め込みます。ハイライトの連動・ON／OFF・ページリンクもネットワークやアプリなしで利用できます。

### 大容量ファイル

アップロードはメモリへ一括読み込みせず、作業フォルダーへ直接保存します。解析ではXML構造だけを読み込み、画像は分割ハッシュで比較します。動画など比較に不要なバイナリはメモリに展開しません。

展開後の合計は60GBまで、XML構造情報は1パーツ64MB・合計512MBまでです。最大サイズ2資料の比較には、アップロード2本と描画用コピー分（最大45GB）に加え、比較画像やPowerPoint自身の作業領域が必要です。PowerPointで開ける大きさ・速度はPCのメモリ、空き容量、Officeの仕様にも依存します。15GB実ファイルによる負荷試験は行っていません。

## 比較の範囲と注意点

- スライド上のテキストボックス・表のセル・グループ内部を解析します。図形IDを優先し、未対応の図形は種類・位置・サイズの近さで対応付けます。推定結果は「要確認」と表示します。同じIDでも全く別の図形に作り替えられた場合は、人の確認が必要です。
- 文字内容の変更と書式・配置の変更を分けます。直接指定されたフォント・サイズ・太字・斜体・文字色・配置と、書式の並びを比較します。訳文の文字単位の対応や意味は推定しません。段落構成の変化が書式変更として表示されることがあります。
- テーマ・マスター・レイアウトの変更はページ全体の要確認として表示します。継承書式の変更箇所を個々の文字まで特定する機能はありません。
- 画像の内容はハッシュで比較します。画像差分は翻訳や描画の違いも含む補助表示です。画像内の文字、SmartArt、グラフ内部、回転・反転グループ内の正確なハイライト範囲は目視確認してください。
- 表記揺れの集約は、テキストボックスまたは表セル内の改行で分けた行ごとの同一原文が対象です。文の部分一致、誤訳の意味判定、OCRは行いません。未対応の原文要素は削除候補として確認してください。
- 静止スライドのみ。**動画・音声を含む資料も読み込めますが、再生情報・参照・再生スケジュールは作業用コピーから除外**し、保存済みのサムネイルだけを比較します。動画本体・リンク先・欠落した動画は開かず、PowerPointの参照回復機能も使いません。サムネイルがない場合は同じ位置・寸法の無地の代替枠を使います。動画本体の内容差分は判定しません。除外したページ・要素を画面・HTML・診断サマリーに表示し、元ファイルは変更しません。
- GIF（アニメーションGIFを含む）は通常の画像として読み込み、比較画面には静止スライドを表示します。GIF・画像の補助参照が欠落している場合は、取得できる主画像を残して補助参照だけを除外します。本体がない場合は埋め込み済みの代替画像、なければ同じ位置・寸法の代替枠を使います。背景や図形の画像塗りつぶしがない場合は無地で表示します。失われた画像は復元せず、対象ページ・図形を画面・HTML・診断サマリーに記録します。正常なGIFのバイナリと元ファイルは変更しません。
- 画像参照のURI表記とZIP内の名前が異なる場合は、実在する画像を確認して作業用コピーの参照表記を合わせます。外部画像は取得しません。
- 旧形式 `.ppt`、マクロ・ActiveX、暗号化、動画・音声以外の外部画像・OLE等の外部参照には対応しません。スライド・レイアウトなど必須パーツの欠落はエラーとして区別します。通常のハイパーリンクは辿りません。
- 読み込み・描画エラーは、資料の種類（日本語原本／英訳版）、処理段階、判明しているページ番号、エラーコード、対処方法を表示します。「技術情報」に内部ファイル名・図形ID・例外・HRESULT・Officeの説明を表示します。解析できるPPTXでも、PowerPoint側の保護や環境によって開けない場合があります。
- PowerPointは専用の子プロセスから直列操作します。専用の一時コピーを読み取り専用で開き、閉じるのはそのコピーだけです。`Application.HWND` による識別やPowerPoint全体の終了は行いません。PowerPointの空のウィンドウ・プロセスが残る場合は手動で終了できます。
- マクロ無効化・警告表示の設定は、資料を開いた直後に元の値へ戻します。失敗時も復元を試み、後処理の失敗を元のエラーに併記します。一時的なRPC拒否のみ、最大8回・合計9秒の待機で再試行します。
- 資料を開く処理は最大900秒、それ以外は同じ処理段階で300秒進捗がない場合、PawapoDiffの描画ワーカーのみを停止します。PowerPointは終了しません。タイムアウト時は設定復元・一時コピーの削除ができていない可能性があるため、資料を保存してPowerPointを再起動してください。
- エラー画面の「診断ログを保存」から、**`diagnostic-summary.txt`（日本語の診断サマリー）・`diagnostic-summary.json`・親プロセスと描画ワーカーの直近20ログファイル**をZIPで取得できます。ログファイルを書けない環境でもサマリーを作成します。サマリーにはアプリ版・OS・Pythonのbit数・作業ドライブの空き容量・入力バイト数・ページ数・経過秒・処理の履歴・例外の詳細を記録します。想定済みの入力エラーやアップロード失敗も記録し、空のログだけになることを防ぎます。通常 `%LOCALAPPDATA%\PawapoDiff\logs\pawapodiff-<プロセスID>.log` に保存します（プロセスごとに最大2MB×3ファイル、7日より古いものは削除を試みます）。書き込めない場合はOSの一時フォルダーを使用します。処理段階・エラー・例外を記録し、スライド本文や認証トークンは記録しません。ローカルのパス等が含まれるため、共有前に内容をご確認ください。
- 座標を取得できない図形・グループや未対応の書式があっても、取得できた文章と他のページの解析を続けます。解析が不完全な場合は画面・HTMLに対象ページと図形IDを必ず表示し、要確認として扱います。不明な座標・書式を確定した変更とは判定しません。解析対象外の項目は画像で確認してください。
- 比較用の描画は全体幅3840pxで行います。
- サーバーは127.0.0.1のみ。起動ごとのトークンとHost/Origin検査でAPIを保護します。PowerPointのインストール・ライセンス認証は利用者側で必要です。

## 読み込みで止まった場合

200ページというページ数だけで拒否する制限はありません。処理中は資料・段階・ページ進捗・経過秒を表示します。次の原因を区別します。

| エラーコード例 | 原因と対応 |
| --- | --- |
| `INVALID_PACKAGE` / `NOT_PPTX` | 圧縮データ破損、暗号化・権限保護、旧PPT、未完了のダウンロード等。PowerPointで直接開き、保護や修復要求を確認してください。拡張子を変更するだけでは変換できません。 |
| `STRICT_OOXML` | Strict Open XML形式。名前を付けて保存で、Strictではない通常の「PowerPointプレゼンテーション (*.pptx)」を選んでください。 |
| `INVALID_XML` / `MISSING_PART` | 内部XMLやスライド・レイアウトなどの必須パーツの欠落。技術情報に内部ファイル名を表示します。動画やGIF・画像の欠落参照は作業用コピーから除外し、取得可能な画像・代替枠で比較を続けます。 |
| `EXTERNAL_REFERENCE` / `ACTIVE_CONTENT` | 動画・音声以外のリンクされたExcel・画像、マクロ・ActiveX等。リンク解除・埋め込み等を行ったコピーが必要です。外部参照やマクロは自動実行しません。 |
| `XML_SIZE_LIMIT` / `EXPANDED_SIZE_LIMIT` | 構造情報または展開後サイズが上限超過。複雑な資料は分割してください。 |
| `DISK_FULL` / `MEMORY_EXHAUSTED` / `ACCESS_DENIED` | 空き容量・メモリ・作業フォルダーの権限の問題。OSの一時ドライブや会社のセキュリティ制限も確認してください。 |
| `POWERPOINT_NOT_INSTALLED` / `POWERPOINT_START_FAILED` | デスクトップ版PowerPointの導入・初回設定・認証・自動操作制限を確認してください。 |
| `POWERPOINT_OPEN_FAILED` / `OFFICE_ACCESS_DENIED` | 構造は読めてもPowerPointが開けない状態。保護ビュー・パスワード・権限保護・ライセンス認証・修復要求等を手動で確認してください。保護は自動解除しません。 |
| `POWERPOINT_BUSY` / `POWERPOINT_TIMEOUT` / `POWERPOINT_DISCONNECTED` | ダイアログ、長時間応答停止、Officeの異常終了等。開いている資料を保存してからPowerPointを再起動し、必要なら資料を分割してください。 |
| `ANALYSIS_FAILED` / `UNEXPECTED_ERROR` | まだ対応できていない構造や例外。エラーが出た同じ画面で診断ログを保存してください。 |

ログはローカルにのみ保存します。サマリーにスライド本文は含めませんが、例外やログにはパス等が含まれる場合があるため、共有前にご確認ください。再起動前のエラーの詳しいサマリーは、エラーが出た起動中に保存してください。

## 開発用セットアップ

Python 3.12、Node.js 22以降を推奨します。以下はリポジトリのルートで実行します。

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
cd frontend
npm ci
npm run build
cd ..
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe -m pawapodiff
```

Linuxでも `.venv/bin/python` で解析・APIテストとUIビルドを実行できますが、実際のスライド描画にはWindows版PowerPointが必要です。起動後の画面はFastAPIが `frontend/dist` から配信します。開発用Vite単独ではAPIに接続しません。

依存の直接バージョンはrequirementsとpackage.jsonで固定し、フロントエンドはpackage-lock.jsonで固定しています。Pythonの推移依存はpipが解決します。

### Windows配布物の生成

```powershell
powershell -ExecutionPolicy Bypass -File scripts/build-windows.ps1
```

配布するファイルは **`dist/PawapoDiff-Setup.exe`** です。アプリ本体・Python・依存ライブラリ・ビルド済みUIを内包した、オフラインのユーザー単位インストーラーです。ペイロードのSHA-256検証後、一時フォルダーに展開してから導入先に移動します。中断した展開物を完成版として起動しません。管理者権限やシステム全体のPATH変更は不要です。

生成にはPython・Node.jsが必要ですが、利用者には不要です。従来のポータブル版 `dist/PawapoDiff` も生成します。こちらを配布する場合はフォルダー全体が必要です。PowerPoint自体は同梱しません。インストーラーは未署名のため、Windowsが発行元を確認できないと表示する場合があります。CIで同梱するSHA-256ファイルでダウンロード後の整合性も確認できます。

### 検証状況とWindowsで残る確認

Linux上で解析・API・比較画像・子プロセスの異常終了／応答停止のpytest、型チェック、画面ビルドを検証しています。200ページ×2資料の構造比較・API全体（画像部分は代替レンダラー）、特殊な文字色・XMLコメント・座標欠落・グループの変換欠落・内部参照破損・空にならない診断ZIPも検証します。埋め込み動画・外部動画・動画本体欠落・サムネイル欠落・孤立した再生情報、GIF本体・補助画像の欠落、URI表記の違いについて、継続・静止化・原本保全を検証します。200ページ資料の負荷試験と実PowerPointでの動画付き資料の描画確認は未実施です。Windows CIではOfficeを模した実際のIDispatchオブジェクト（HWNDメンバーを持たない）に対し、読み込み・比較用描画・設定復元・後処理のCOM契約を検証します。PowerPoint本体のテストとは区別します。ブラウザ操作は合成画像を返すテスト用レンダラーで検証しています。Windows CIでは配布EXEの導入・子プロセス起動を検証します。PowerPoint本体による描画はCIでは自動実行せず、以下のスモークテストで確認できます。

```powershell
.\.venv\Scripts\python.exe scripts/windows-smoke.py
```

このスクリプトは外部動画参照・動画本体欠落を含む一時PPTXを生成し、PowerPointに渡す前の静止化、PowerPointによる実描画、比較、集約した日英比較表と表記揺らぎ注釈、HTML生成を確認します。追加で配布物をダブルクリックし、以下を手動確認してください。

- Python・Node.js未導入のWindowsでセットアップEXEから初回導入・再起動ができること。スタートメニュー起動、再実行時の再利用、新版の別フォルダー導入を確認すること。
- PowerPoint未起動時と、別資料を開いている状態での比較。既存資料・アプリが閉じないこと。共有した場合も開いた一時コピーだけを閉じ、利用者の資料・設定が維持されること。
- 日本語フォント、表、グループ、SmartArt、グラフを含む実資料で、画像と表示がPowerPointと一致すること。
- HTMLを保存してアプリ終了後にオフラインで開けること。日英比較表の行分割・短文除外・同一原文の集約・各訳の出現ページ・注釈が含まれ、ハイライト連動・ON／OFFも動作すること。
- PowerPoint未導入、破損・暗号化・ページ数不一致・寸法不一致時のメッセージと、正常終了後の一時データ削除。

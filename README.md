# PawapoDiff

日本語原本と英訳版のPowerPointをローカルで比較するWindows用ツールです。図形の配置・サイズ、文字書式、翻訳の表記揺れ候補をブラウザで確認できます。LLM・有料API・外部へのファイル送信は使用しません。

## 利用環境と起動

- Windows 10/11、デスクトップ版Microsoft PowerPoint、Chrome/Edge等。
- **`PawapoDiff-Setup.exe` をダブルクリックするだけで、必要なPython実行環境・依存ライブラリ・画面を自動配置して起動します。** 利用者によるPython・Node.jsの導入や管理者権限は不要です。
- 初回は `%LOCALAPPDATA%\PawapoDiff\versions` に展開し、スタートメニューに「PawapoDiff」を追加します。次回からはそのショートカットで起動できます。セットアップEXEを再実行しても、同じ版は再導入しません。新版は別フォルダーに導入します。
- 必要な環境はEXEに同梱するため、導入・使用時ともインターネット接続は不要です。**PowerPoint本体の導入・ライセンス認証は別途必要です。**
- 不要になった場合はアプリを終了後、上記のPawapoDiffフォルダーとスタートメニューのショートカットを削除してください。自動更新は行いません。
- 終了は起動したコンソールで **Ctrl+C**。ブラウザを閉じるだけではサーバーは終了しません。通常終了時に一時ファイルを削除します。強制終了時はOSの一時フォルダーに `PawapoDiff-*` が残る場合があります。
- インストーラーはGitHubの [Actions → Windows installer](https://github.com/7cancer/PawapoDiff/actions/workflows/windows-build.yml) の成功した実行から、Artifactsの **PawapoDiff-Windows-Setup** をダウンロードし、ZIPを展開して取り出せます（GitHubへのログインが必要です）。mainへのPushで自動ビルドします。
- ソースのZIPにはビルド済みEXEは含みません。手元で生成する場合は下記のWindowsビルド手順を使います。

## 使い方

1. 「原本」と「英訳版」に、同じページ数・寸法の `.pptx` を選択して比較を開始します。各800MB、展開後4GBまでです。
2. ページ一覧からページを選択します。左右・重ね合わせ・画像差分の各表示で確認できます。オレンジの枠は構造上の変更候補です。
3. 位置とサイズはptで比較します。初期閾値1pt（約1.33px、96dpi換算）を変更して再判定できます。画像の書き出し解像度によってpx換算は変わります。
4. 翻訳チェックで、同一原文の訳し分け、空の訳文、日本語の残存を確認します。HTMLレポートには全ページの比較画像・変更一覧・翻訳チェックを埋め込みます。ネットワークやアプリなしで開けます。
5. 画像保存はHD／フルHD／4Kの枠に縦横比を保って収め、余白は足しません。カスタムでは代表ページ上で矩形をドラッグし、出力幅を入力します。全ページを同じ相対範囲で切り抜き、連番PNG入りZIPを保存します。原本だけの選択でも画像出力できます。

## 比較の範囲と注意点

- スライド上のテキストボックス・表のセル・グループ内部を解析します。図形IDを優先し、未対応の図形は種類・位置・サイズの近さで対応付けます。推定結果は「要確認」と表示します。同じIDでも全く別の図形に作り替えられた場合は、人の確認が必要です。
- 文字内容の変更と書式・配置の変更を分けます。直接指定されたフォント・サイズ・太字・斜体・文字色・配置と、書式の並びを比較します。訳文の文字単位の対応や意味は推定しません。段落構成の変化が書式変更として表示されることがあります。
- テーマ・マスター・レイアウトの変更はページ全体の要確認として表示します。継承書式の変更箇所を個々の文字まで特定する機能はありません。
- 画像の内容はハッシュで比較します。画像差分は翻訳や描画の違いも含む補助表示です。画像内の文字、SmartArt、グラフ内部、回転・反転グループ内の正確なハイライト範囲は目視確認してください。
- 表記揺れの集約は、テキストボックスまたは表セル単位で空白・改行を正規化した同一原文が対象です。文の部分一致、誤訳の意味判定、OCRは行いません。未対応の原文要素は削除候補として確認してください。
- 静止スライドのみ。旧形式 `.ppt`、マクロ・ActiveX、暗号化、外部メディア・OLE等の外部参照には対応しません。通常のハイパーリンクは辿りません。
- PowerPointは専用ワーカーで直列操作し、読取専用で開きます。既存のPowerPointプロセスを共有してしまった場合は、そのプロセスを閉じずに中断します。メッセージに従って資料を保存・PowerPointを終了し、再試行してください。
- 描画は全体幅3840pxで行います。極端に大きいカスタム出力・狭い切り抜きでは補間画像になり、細部の情報量は増えません。
- サーバーは127.0.0.1のみ。起動ごとのトークンとHost/Origin検査でAPIを保護します。PowerPointのインストール・ライセンス認証は利用者側で必要です。

## 開発用セットアップ

Python 3.12、Node.js 22以降を推奨します。以下はリポジトリのルートで実行します。

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
cd frontend
npm ci
npm run build
cd ..
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe -m pawapodiff
```

Linuxでも `.venv/bin/python` で解析・APIテストとUIビルドを実行できますが、実際のスライド描画にはWindows版PowerPointが必要です。起動後の画面はFastAPIが `frontend/dist` から配信します。開発用Vite単独ではAPIに接続しません。

依存の直接バージョンはrequirementsとpackage.jsonで固定し、フロントエンドはpackage-lock.jsonで固定しています。Pythonの推移依存はpipが解決します。

### Windows配布物の生成

```powershell
powershell -ExecutionPolicy Bypass -File scripts/build-windows.ps1
```

配布するファイルは **`dist/PawapoDiff-Setup.exe`** です。アプリ本体・Python・依存ライブラリ・ビルド済みUIを内包した、オフラインのユーザー単位インストーラーです。ペイロードのSHA-256検証後、一時フォルダーに展開してから導入先に移動します。中断した展開物を完成版として起動しません。管理者権限やシステム全体のPATH変更は不要です。

生成にはPython・Node.jsが必要ですが、利用者には不要です。従来のポータブル版 `dist/PawapoDiff` も生成します。こちらを配布する場合はフォルダー全体が必要です。PowerPoint自体は同梱しません。インストーラーは未署名のため、Windowsが発行元を確認できないと表示する場合があります。CIで同梱するSHA-256ファイルでダウンロード後の整合性も確認できます。

### 検証状況とWindowsで残る確認

Linux上で解析・API・画像出力のpytest、TypeScript型チェック、Viteビルドを検証しています。ブラウザ操作は合成画像を返すテスト用レンダラーで検証しています。**PowerPoint COM描画、Windows実行ファイルの生成・起動はLinuxでは検証できていません。Windowsで以下を通すまで、リリース完成とは扱いません。**

```powershell
.\.venv\Scripts\python.exe scripts/windows-smoke.py
```

このスクリプトは一時PPTXを生成し、PowerPointによる実描画、比較、3種類の解像度・切り抜き出力、HTML生成を確認します。追加で配布物をダブルクリックし、以下を手動確認してください。

- Python・Node.js未導入のWindowsでセットアップEXEから初回導入・再起動ができること。スタートメニュー起動、再実行時の再利用、新版の別フォルダー導入を確認すること。
- PowerPoint未起動時と、別資料を開いている状態での比較。既存資料・アプリが閉じないこと。プロセス共有時には安全に中断すること。
- 日本語フォント、表、グループ、SmartArt、グラフを含む実資料で、画像と表示がPowerPointと一致すること。
- HTMLを保存してアプリ終了後にオフラインで開けること。PNG出力の枚数・寸法・切り抜き範囲が正しいこと。
- PowerPoint未導入、破損・暗号化・ページ数不一致・寸法不一致時のメッセージと、正常終了後の一時データ削除。
